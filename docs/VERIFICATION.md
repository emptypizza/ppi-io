# 검증 기록 · 2026-11-07

## 완료

- TypeScript 검사, 시뮬레이션·프로토콜·무료 플랜 차단·저장·입력·예산·연결의 단위 테스트51개 통과.
- 실제 workerd/SQLite Durable Objects 통합 테스트9개 통과. 두 클라이언트의 같은 방·맵,20명/2방 상한과21번째 차단,예산 소진,재접속 교체,프로세스 재생성,세대와티켓 재사용 차단을 확인.
- 20개 WebSocket 클라이언트가 두 방에서71,169ms 동안 두 라운드를 진행. 정상 경기 결과20개 수신,예상하지 않은 연결 종료와 JS 오류0. 초당10회 입력의 전송 지터 문제를 토큰 버킷으로 수정한 뒤 재검증.
- 상태 패킷95백분위4KiB 이하를10명·5개 seed의 총격 시뮬레이션으로 검사.
- Chromium 실제 두 브라우저가 같은 경기에서 사람2명/봇8명,기본HP400·맨손으로 접속하고 키 입력 이동을 확인.
- 연습의 강화HP450·시작소총·이동·급강하·전투·결과·재시작,저장 구매 후 재로드와 원본 저장 키 미변경을 확인.
- 표준 web-game 클라이언트3회 입력/스크린샷 반복 통과. 그림과 상태를 확인.
- Chromium·WebKit의 연습,온라인 미설정 안내,좁은 화면·리사이즈 확인. Chromium 전체 화면·Escape 확인.
- 실제 Safari27.0.1의 공개 사이트에서 연습 시작,지상전 렌더링·타이머59→50→39,HP변화400→350,메뉴 복귀와 새 연습 입장을 확인. 초기 캡처의 일시적인 빈 화면은 이후 재확인에서 재현되지 않았으며 원인을 확정하지 못함.
- 공개 HTML·설정·JS·CSS가 로컬 빌드와 바이트 단위로 일치. GitHub Actions42338758903의 전체 검사와 Pages 배포 성공.
- 접속 취소 후 늦은 인증 콜백이 새 연습 경기를 방해하지 않는 것을 확인.
- 스크린샷을 실제 열어 메뉴·훈련소·강하·전투·결과·두 인간 접속 화면을 검토.
- Cloudflare 인증이 없으면 배포 스크립트가 중단되는 것을 확인. 비밀 키와 개발용 우회는 공개 빌드에 포함하지 않음.

## 미완료 외부 검증

- Cloudflare 계정 생성·이메일 인증·Wrangler 로그인·Workers Free 실제 계정 확인.
- 관리형 백엔드 배포와 실제 Turnstile 검증 후 온라인 개방.
- 서로 다른 두 실제 기기·인터넷 회선에서 PvP와RTT 측정.
- 실제 Edge 검증. Safari 기본 연습 검증을 온라인 실서비스 검증으로 확대하지 않음.
- Firefox는 애플리케이션 페이지 생성 전macOS sandbox/SWGL 실행 오류로 미검증. 프로젝트 오류라고 단정하지 않음.

이 항목이 남아 있는 동안 공개 사이트는 봇 연습을 제공하고 온라인은 닫힌 상태입니다.
